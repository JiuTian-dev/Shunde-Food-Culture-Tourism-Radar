# 顺德美食流量孵化引擎 🐔🔥

> 帮更多顺德美食，复现「莫氏鸡煲」的流量奇迹。
> 一个专为顺德文旅与宣传部门打造的 **AI Agent 矩阵**：主动在社媒"声呐"中听见那些**还没爆、但该爆**的本地美食店，用多智能体协作把"网红偶然性"变成**可计算的潜力**。

---

## 一句话

**诊断医师 + 流量预言师** 两个 Agent，现场给任何一家顺德美食店打分、排风险、算流量量级与变现回报——评委看到的是"**可计算的爆款**"。

### 看板能做什么
| 功能 | 说明 |
|---|---|
| 📊 潜力榜 | 36 家顺德美食店按爆款指数排序，A 类"重点孵化"置顶 |
| 📁 店铺档案 | 品类/主理人人设/视觉卖点/定价能力/事实依据，全部可溯源 |

### 两种运行模式（演示永不中断）
- **内置回放模式（默认）**：无 API Key 也能跑，返回已经固化的 25 家诊断 + 7 家预测报告（`output/`）。
- **千问 LLM Agent 模式（真实）**：设置下面两个环境变量后，诊断与预测由千问模型**实时推理**生成。

```bash
# Windows（PowerShell）
$env:QWEN_API_KEY="你的key"
$env:QWEN_MODEL="qwen-plus"          # 可换 qwen-max / qwen-turbo
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

> 看板右上角状态徽章会显示当前是「千问 Agent 在线」还是「内置报告回放」。
> 调用失败时自动回退到内置报告，Demo 现场绝不会卡住。

## 这套系统的核心逻辑

### 爆款不是玄学，是可计算的
```
爆款指数 = 0.25×人设反差度 + 0.25×风味品相度 + 0.20×故事叙事性
        + 0.20×情绪共鸣度 + 0.10×素材续航度
```
| 等级 | 区间 | 处置 |
|---|---|---|
| **A** | ≥75 | 重点孵化（直接进入策划传播） |
| **B** | 60–75 | 待观察（补齐短板再孵化） |
| **C** | <60 | 不推荐（避免浪费资源） |

### 风险是门槛，不是加分
- 🔴 **红线**（卫生/安全/资质违规）→ 一票否决
- 🟡 **黄线**（产能不足/主理人抗拒/健康因素）→ 降级"需先扶持"
- ⚪ **提示项** → 执行时注意

### 流量预言：对标莫氏法（不依赖训练数据）
把「莫氏鸡煲」当锚点（爆款指数 94.1 = 引爆力 1.0、曝光 1.5 亿、客流 3000 人/日、周期约 3 个月），
对任何一家店：`引爆力 = min(指数/94.1, 1)`，`曝光 = 1.5亿 × 引爆力 × 品类系数`，
`周期 = 2 + 素材续航/100 个月`，**产能硬约束封顶**——先算能不能接住流量，再谈放大。

### 变现回报（投资型评委视角）
每家 A/B 类给出：门店营收增量、直播 GMV、品类溢出价值、扶持资源投入分——回答评委最关心的"**投这笔宣传费，回报是什么**"。

---

## 北极星指标（评委看这三个数字）
1. **命中率**：A 类里最终爆的比例（莫氏 = 100% 命中）
2. **提前量**：比网红爆发早多久介入（本引擎的目标是"提前 1 个月听见"）
3. **回报杠杆**：每 1 元扶持换来的曝光/营收（莫氏 ≈ 1.5 亿曝光几乎零成本自传播）

## 数据集：真实、可溯源

36 家店全部来自真实公开信息（网易《寻味顺德》系列、小红书/抖音传播事件、新闻报道），每条带 `evidence`（来源+链接+日期）。正样本 3 家（已验证爆款）、负样本 8 家（有名但没爆，用于校准打分）、候选池 25 家。

**已跑通的方法论验证**（`docs/诊断报告_单元测试.md`）：莫氏鸡煲→A(94.1)、民信老铺→C(42.75)、无招牌老夫妻→A-(86.8)——全部符合真实情况。

# 技术架构、工作流程与制作说明

## 一、技术架构

```text
浏览器 Web 看板
  ├─ 城市地图 / 店铺节点 / 潜力榜
  ├─ 政府助推快速方案 / 全屏方案书
  └─ 小顺流式对话
          │ HTTP / SSE
          ▼
FastAPI + Uvicorn
  ├─ /api/shops、/api/locations、/api/leaderboard
  ├─ /api/diagnose、/api/forecast
  ├─ /api/workflow/run
  └─ /api/chat
          │
          ├─ 本地规则引擎：快速方案、数据评分、风险校验
          ├─ YAML / JSON：店铺、事件、位置、诊断与预测数据
          └─ DeepSeek OpenAI-compatible API：小顺实时聊天
```

## 二、主要技术栈

| 层级 | 技术 |
|---|---|
| 前端 | 原生 HTML / CSS / JavaScript，单页 Web 看板 |
| 地图视觉 | 本地地图素材、CSS 3D 感、节点动画、拖拽缩放 |
| 后端 | Python、FastAPI、Uvicorn |
| 数据 | YAML、JSON、本地文件化数据集 |
| AI 接口 | OpenAI 兼容客户端，接入 DeepSeek V4 Flash |
| 交互协议 | REST API、SSE 流式输出 |
| 测试 | Node JS 语法检查、FastAPI 导入检查、浏览器点击回归 |

## 三、数据与 Agent 工作流

```text
真实店铺资料
  → 数据加载与五维评分
  → 雷达发现潜力店铺
  → 资产卡提取人物 / 菜品 / 视觉 / 承载
  → 星火指数评估传播与转化
  → 创意策源生成内容脚本
  → 作战包拆分 90 天行动
  → 战情室补充客流、风险与复盘建议
  → 前端输出地图、方案卡和方案书
```

## 四、快速方案与 AI 对话的分工

- 政府助推方案：使用本地规则引擎和结构化资料，默认快速返回，保证现场体验；准备了多个真实店铺轮换，不依赖单一固定示例。
- 小顺聊天：使用 DeepSeek V4 Flash，通过 SSE 流式返回文本，适合现场追问和个性化解释。
- 诊断与预测模块：支持真实模型增强；模型不可用时自动回退到已固化的规则结果，保证演示不中断。

## 五、制作与验证记录

- 解决 FastAPI / Uvicorn 启动与依赖问题。
- 接入地图、Logo、小顺 IP 和店铺节点素材。
- 修复节点重叠、标签拦截点击、移动端布局和方案书弹层问题。
- 用浏览器实际点击验证地图节点、潜力榜、方案生成、方案书目录、小顺聊天和移动端页面。
- 最终页面 JavaScript 语法检查通过，主要 API 返回 200。

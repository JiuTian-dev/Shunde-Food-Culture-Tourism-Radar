# 项目说明与解决方案

## 一、我们解决什么问题

顺德有大量真实、有手艺、有地方记忆的美食店，但“值得被看见”不等于“自然会爆”。政府、街区和商户在做文旅推广时，常遇到四个问题：

1. 资源很多，但不知道优先扶持哪家店。
2. 店铺有故事，但难以拆成可传播的内容资产。
3. 流量增长后，产能、排队、停车和食品安全风险可能被忽略。
4. 方案容易停留在口号，缺少指标、动作、负责人和复盘周期。

## 二、解决方案

“顺德寻味 · 城市增长驾驶舱”是一个专为顺德文旅与宣传部门打造的 AI Agent 系统：以社媒声呐为未来接入口，主动听见那些还没爆、但该爆的本地美食店和主理人故事，由单 Agent 完成“发现—挖掘—诊断—预测—传播”的全链路，把“网红偶然性”变成“可计算的潜力”。当前 Demo 以顺德真实店铺数据演示核心流程，后续可接入更大规模的社媒数据源。

### 1. 发现：建立顺德味觉地图

把店铺名称、品类、镇街、坐标和潜力指数放入地图，形成可点击的城市味觉节点。

### 2. 诊断：计算爆款潜力，而不是凭感觉选店

核心指数由五个维度组成：

`爆款指数 = 0.25 × 人设反差度 + 0.25 × 风味品相度 + 0.20 × 故事叙事性 + 0.20 × 情绪共鸣度 + 0.10 × 素材续航度`

同时设置风险门槛：卫生、安全、资质问题优先于传播潜力；产能不足、主理人抗拒和承载边界则触发降级或先扶持策略。

### 3. 预测：用莫氏鸡煲作为引爆力锚点

系统把莫氏鸡煲作为已验证案例锚点，结合店铺指数、品类系数、素材续航与承载能力，输出曝光、客流、排队、周期和变现回报的可解释估算。预测结果是决策辅助，不冒充真实经营承诺。

### 4. 策源：把一家店变成一份城市行动方案

系统围绕目标店铺生成：

- 店铺故事与人物主张
- 15 秒、30 秒、180 秒内容脚本
- 官方号、达人、商户账号协同矩阵
- 90 天推进节奏
- 打卡点、路线、消费券和交通承接建议
- 产能、排队、食品安全与舆情风险清单

### 5. 交付：用高级可视化让决策者看懂

前端以 3D 感城市地图为核心，提供店铺节点点击、潜力榜、方案生成、小顺 IP 对话助手和全屏方案书。方案书不是结构化文本堆叠，而是按章节展示真实店铺资料、内容脚本、行动表和风险依据。

## 三、核心用户

- 文旅与宣传部门：寻找值得扶持的本地内容火种。
- 镇街与街区运营者：组织路线、导览、消费券和公共服务。
- 美食商户：知道自己为什么值得传播，以及流量来了如何接住。
- 本地达人与高校创作者：获得真实、可拍、可复用的内容题材。

## 四、项目价值

### 对政府

从“平均用力宣传”转向“按潜力与风险分层扶持”，形成可解释的资源配置依据。

### 对商户

把手艺、人物和店铺现场转化为可执行内容，不要求所有店都变成同一种网红店。

### 对城市

把单店流量接入镇街路线、导览、消费服务与城市 IP，推动从一次曝光到长期留量。

# AI 工具、模型、素材、开源组件及真实性承诺

## 一、AI 工具与模型

| 工具 / 模型 | 使用位置 | 用途 |
|---|---|---|
| DeepSeek V4 Flash | 小顺流式对话；可选的 Agent 增强 | 回答顺德美食、路线和文旅执行问题 |
| 规则引擎 | 政府助推快速方案、评分、风险校验 | 保证快速、可解释、可复现的方案输出 |
| Codex / AI 编程协作 | 项目开发过程 | 协助前后端代码、交互、测试和文案整理 |

## 二、素材与数据

- 顺德店铺资料：来自项目 `data/` 数据集，包含店铺名称、品类、镇街、人物背景、制作技艺、潜力维度、风险和 evidence 来源字段。
- 地图素材：项目本地地图图片，用于顺德区域可视化。
- 小顺 IP：项目本地图片素材，用于数字人头像、方案书提示卡和页面视觉识别。
- Logo：项目本地 `logo图标.png`，用于驾驶舱品牌标识。
- 展示截图：来自项目实际运行页面的 Playwright 回归截图。

## 三、开源组件与依赖

- FastAPI：后端 Web API 框架。
- Uvicorn：ASGI 服务运行器。
- PyYAML：YAML 数据读取。
- Pydantic：请求数据校验。
- OpenAI Python Client：调用 OpenAI-compatible 的 DeepSeek 接口。
- 浏览器自动化工具：用于页面回归测试与截图验证。

## 四、关于 Figma、Blender 与像素地图工具

本项目最终版本没有使用 Figma、Blender 或 `pixelmap.amcharts.com`，因此没有对应的工具产出需要申报。页面视觉、地图交互和素材整合均在项目代码与本地资源中完成。

| 工具 | 是否进入最终版本 | 具体产出 / 文件 |
|---|---|---|
| Figma | 否 | 无对应最终产出 |
| Blender | 否 | 无对应最终产出 |
| pixelmap.amcharts.com | 否 | 无对应最终产出 |

## 五、真实性承诺

1. 本项目不会把模型生成内容冒充为官方统计、实地采访、真实订单或已发生的商业结果。
2. 店铺信息以项目数据集中的公开来源和 evidence 字段为依据；信息不足处会标记“待核”，不主动编造。
3. 爆款指数、曝光、客流、排队和变现结果属于模型 / 规则估算或演示数据，不能替代经营统计和政府口径。
4. 方案中的风险提示优先级高于传播建议；食品安全、资质和承载能力需要线下复核。
5. API Key 仅保存在本地环境变量，不写入前端页面、截图、提交文档或公开代码。
6. 最终提交时，团队会再次核对成员、素材授权、外部链接、模型名称和版本信息。

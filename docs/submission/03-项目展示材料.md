# 项目展示材料

## 一、展示主线

展示建议按“看见问题—点开地图—选择店铺—生成方案—查看方案书—询问小顺”的顺序进行，控制在 3–5 分钟内。

### 01 开场：一张地图，点燃一城味道

展示城市地图、顺德店铺节点和“小顺 · 城市策源助手”。说明系统不是单纯展示店铺，而是把店铺资料、内容势能和公共承接放在同一张决策地图上。

### 02 点击店铺：从一个真实小店开始

点击莫氏鸡煲、美姐粥苑或糖沙翁小店，展示店铺品类、镇街、故事、视觉卖点、潜力指数与风险信息。

### 03 生成方案：从潜力判断到行动安排

点击“政府助推 · 文旅增长方案”，展示快速生成的城市行动方案。方案会轮换不同店铺，并基于对应店铺资料生成，不固定使用单一示例。

### 04 打开完整方案书：让方案可以被阅读和执行

展示全屏方案书的四个章节：真实店铺画像、90 天路线、内容资产、承载与风险。重点强调方案中的菜品、人物、画面和经营边界来自对应店铺数据。

### 05 小顺对话：让评委现场追问

进入“小顺 · 文旅策划搭子”，可询问“给一家店做周末路线”“为什么这家店值得扶持”“如何避免爆火后排队失控”等问题，展示 DeepSeek 流式回答。

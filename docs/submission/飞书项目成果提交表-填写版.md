## 12. Demo 演示说明

打开 Demo 后，按以下顺序演示：

1. 查看顺德城市地图和店铺节点。
2. 点击莫氏鸡煲、美姐粥苑或糖沙翁小店，查看店铺故事、品类、潜力指数和风险。
3. 点击“政府助推 · 文旅增长方案”，快速生成对应店铺的城市行动方案。
4. 点击“打开完整方案书”，查看真实店铺画像、90 天路线、内容资产、承载与风险。
5. 点击“小顺助手”，询问“给一家店做周末路线”或“如何避免爆火后排队失控”。

运行环境：Windows / Python 3.12+ / FastAPI / Uvicorn。若使用本地版本，进入项目目录后运行：

```powershell
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

政府助推方案默认使用本地规则引擎，生成速度快；小顺聊天使用 DeepSeek 流式接口。现场演示前建议提前打开页面并准备截图或视频作为备用。

## 16. AI 工具、模型、素材及开源组件说明

本项目使用 DeepSeek V4 Flash 用于“小顺 · 文旅策划搭子”的实时流式对话；政府助推 · 文旅增长方案使用本地规则引擎和结构化店铺资料，保证快速、可解释和可复现。项目使用 Codex / AI 编程协作辅助前后端开发、交互优化、测试和文案整理。

技术组件包括 FastAPI、Uvicorn、PyYAML、Pydantic、OpenAI Python Client，分别用于 Web API、服务运行、YAML 数据读取、请求校验和调用 OpenAI-compatible 的 DeepSeek 接口。

外部数据与素材主要来自项目 `data/` 店铺数据集及其 evidence 来源字段；地图、Logo、小顺 IP 和展示截图为项目本地资源。Figma、Blender、pixelmap.amcharts.com 均未使用。项目不将模型生成内容冒充官方统计、实地采访、真实订单或已发生的商业结果；预测数据和潜力指数属于规则 / 模型估算，信息不足处标记为待核。

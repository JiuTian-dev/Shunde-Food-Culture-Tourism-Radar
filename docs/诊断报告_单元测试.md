## 样本 1：莫氏鸡煲（SD-P01）→ 期望 A

### ① 事实核验
字段完整，`lifetime` 完整（含引爆/峰值/退潮/平稳四阶段），证据 4 条。✅ `verified: true`

### ② 逐维评估（证据 → 锚点 → 分数 → 理由）

**人设反差度：98**
- 证据：5 条劝退金句（"别拍太火，生意太忙我做不了啊""喝汤可能拉肚子""早日倒闭，才能早日开心"）+ 佛系/耿直/反套路人格
- 锚点：95-100 档"劝退/自黑/金句级反差，反流量言行成套出现" ✅ 完全吻合且已被市场验证
- 独立判断：与预评分 98 一致

**风味品相度：92**
- 证据：现宰 180 天走地鸡 + 药膳汤底（土茯苓/五指毛桃/老陈皮）+ 不预制 + 炭炉瓦煲出片
- 锚点：90+ 档"现宰+强出片" ✅
- 独立判断：92。被 7 小时排队验证过真实品质，含金量高于普通 90

**故事叙事性：95**
- 证据：老中医转行 → 欠债 180 万 → 靠流量还清，完整人生弧光
- 锚点：90+ 档"完整人生弧光" ✅
- 独立判断：95

**情绪共鸣度：97**
- 证据：话题破 5 亿；媒体归因"击中'不被商业收编的真实'"；爆红前是街坊店
- 锚点：90+ 档"原生真诚，击中时代情绪" ✅
- 独立判断：97

**素材续航度：82**
- 证据：金句/斩鸡工艺/汤底养生/排队奇观/直播带货，内容线丰富
- 锚点：70-90 档"可拍 20+ 条" ✅ 品类聚焦鸡煲略窄，压到 82
- 独立判断：82

### ③ 爆款指数
`98×0.25 + 92×0.25 + 95×0.2 + 97×0.2 + 82×0.1 = 94.1`

### ④ 风险审查
- 🔴 红线：无
- 🟡 黄线 4 条：产能严重不足（峰值 6000 人/排队 7h）、老板健康透支、供应链替换（温氏土鸡争议）、商业化与人设反差争议
- 判定：无红线 → 不否决；黄线多但均可通过"扶持预案"管理

### ⑤ 压力测试 + 结论
- **会爆**：劝退人设 + 现宰画面 + 还债故事，情绪价值拉满
- **会崩**：产能（10 桌→200 桌）、老板健康、供应链（日均 200 只超自养）
- **需提前做**：限号、排队区、停车场（"停鸡坪"）、供应链预案、主理人强制休息
- **结论：A 类** ✅（历史已验证：政府连夜修停车场正是承接了这场引爆）

**单元测试 1 通过。**

## 样本 2：民信老铺（SD-N01）→ 期望 C

### ① 事实核验
字段完整。✅ `verified: true`

### ② 逐维评估

**人设反差度：25**
- 证据：`signatureLines` 为空，主理人"鲜少出镜、无故事化表达"
- 锚点：<30 档"无个人人设，品牌化/标准化" ✅
- 独立判断：25（与预评分一致）

**风味品相度：68**
- 证据：双皮奶非遗技艺 + 水牛奶（真实品质）但标准化出品、出片元素一般
- 锚点：50-70 档"出品稳定但无视觉冲击"
- 独立判断：**68**（比预评分 70 略降——非遗加分被"标准化"和"无出片"抵掉。分歧已记录）

**故事叙事性：40**
- 证据：30 年代起家 + 省非遗，**有历史无叙事输出**
- 锚点：40-50 档"有背景但无表达"
- 独立判断：40

**情绪共鸣度：40**
- 证据：游客多、"偏甜"口碑两极、本地认可度下降
- 锚点：35-45 档"无强共鸣点"
- 独立判断：40

**素材续航度：35**
- 证据：单品双皮奶、标准化出品、无梗无场景
- 锚点：<50 档"单品枯竭型"
- 独立判断：35

### ③ 爆款指数
`25×0.25 + 68×0.25 + 40×0.2 + 40×0.2 + 35×0.1 = 42.75`

### ④ 风险审查
- 🔴 红线：无
- 🟡 黄线：本地认可度下降（口碑趋势风险，记提示项）

### ⑤ 压力测试 + 结论
- **会爆**：几乎找不到强引爆点（无画面、无人设梗、无故事）
- **会崩**：已是游客店，若再被引爆只会加重"游客店"标签，本地口碑进一步反噬
- **结论：C 类** ✅ 不值得投入孵化资源
- 深层诊断（最有价值的输出）：民信缺的不是曝光，是**叙事资产**——无人设、无故事、无画面。"有流量≠该爆"，这正是反样本教给模型的最重要一课

**单元测试 2 通过。**

## 样本 3：无招牌老夫妻作坊（SD-C02）→ 期望 A 但需轻推慢放

### ② 逐维评估摘要
- 人设反差度 92（"卖完就收""没有菜单"→ 莫叔原型，金句量略少）
- 风味品相度 85（手磨杏仁糊/柴火砂锅/每日限量 80 块）
- 故事叙事性 85（30 年坚守 + 手写小黑板）
- 情绪共鸣度 95（老街坊记忆，时代稀缺的真实）
- 素材续航度 65（品类窄，低于莫氏）

### ③ 爆款指数
`92×0.25 + 85×0.25 + 85×0.2 + 95×0.2 + 65×0.1 = 86.8` → **A 类**

### ④ 风险审查（降级机制生效）
- 🟡 黄线 2 条：**产能极低**（售罄即收）、**老夫妻健康/体力风险**、不扩张意愿强
- 判定：无红线不否决，但黄线严重 → **A 类但标记"轻推慢放"**

### ⑤ 结论
- 是"该爆"的店，但**扶持必须保护优先**：提前谈限量承接 + 尊重老夫妻意愿，绝不硬推。这是对莫氏教训的正面应用。

**边界测试通过：红黄线机制能正确降级。**

## 测试结论

| 样本 | 期望 | 实际 | 结果 |
|---|---|---|---|
| 莫氏鸡煲 | A | A（94.1） | ✅ |
| 民信老铺 | C | C（42.75） | ✅ |
| 无招牌老夫妻 | A- | A-（86.8，需轻推慢放） | ✅ |

**方法论成立。** 三个测试同时验证了：
1. 五维打分能正确区分"该爆/不该爆"（莫氏 vs 民信 指数差 51 分）
2. 风险门槛机制能正确降级（A→A-）
3. 诊断输出可解释、可追溯（每个分数都有证据链）
4. 反样本的诊断价值体现：民信"有流量≠该爆"，缺的是叙事资产

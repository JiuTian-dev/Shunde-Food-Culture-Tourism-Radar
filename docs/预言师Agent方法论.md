# 流量预言师 Agent · 方法论 v1

> 核心目标：在诊断结论之上，回答三个决策问题——
> 1. **量级**：这家店若被引爆，会是什么量级？（曝光/客流/排队/周期）
> 2. **确定度**：有多确定？（置信区间，诚实表达不确定性）
> 3. **回报**：值不值得投？（变现回报 + 政府溢出价值，投资视角）
>
> 原则：**把"网红偶然性"降低为"可计算的潜力"，但不假装能消除偶然性**——这是产品立意的哲学，也是诚实底线。
> 版本 v1 · 日期 2026-08-14

---

## 一、定位与职责

预言师是五步链路（发现→挖掘→诊断→预测→传播）的**量化决策节点**。

- 输入：诊断报告（含 `stress_test`、`level`、五维分数）+ 店档案
- 只对 **A/B 类** 店做预测（C 类不浪费算力）
- 输出：量级预测 + 置信区间 + 变现回报测算，供政府/投资人分配资源
- 一句话定位：**"诊断医师说清了这家店身体好不好，预言师负责算出它火了能值多少钱、有多大概率火、火多久。"**

---

## 二、标答锚点：莫氏鸡煲全生命周期数据

预测必须以莫氏真实数据为**标尺**（这是全系统唯一的"已验证答案"）：

| 指标 | 莫氏真实数据 |
|---|---|
| 引爆视频 | 单条曝光超 **1.5 亿次**，点赞 150 万+ |
| 话题量级 | 全网话题累计 **破 5 亿**播放 |
| 客流峰值 | 单日 **3000-6000 人**（排队 7 小时） |
| 产能天花板 | 日均 200 只土鸡（超自养后遭口感争议） |
| 爆红周期 | 约 **3 个月**退潮 → 后平稳在日均 100 只 |
| 直播变现 | 近 30 天销售额 **500 万-1000 万** |
| 还债 | 莫叔靠流量还清 **180 万** 欠债 |
| 城市溢出 | 走红两周后佛山**鸡煲消费 +84%** |

这些数字是预测的"基准锚点"。**莫氏爆款指数 94.1 记为标杆值 1.0。**

---

## 三、预测方法：相对莫氏对标法

不追求精确回归（黑客松量级无真实训练数据），用**可解释的对标折算法**，每一步都能讲给评委听。

### 第 1 步：引爆力系数
```
引爆力系数 = min(诊断爆款指数 / 94.1, 1.0)
```
- 指数 94 的店（莫氏同款）→ 系数 1.0；指数 60 → 系数 0.64
- 上限 1.0（不承诺比莫氏更爆）

### 第 2 步：品类传播修正系数（经验值，注明依据）
| 品类 | 系数 | 依据 |
|---|---|---|
| 鸡煲/打边炉 | 1.0 | 莫氏已验证，强出片+强社交属性 |
| 烧鹅/炖汤 | 0.9 | 画面强但偏正餐 |
| 桑拿/蒸鲜 | 0.95 | 蒸汽画面出片，莫氏同源 |
| 粥/煲仔饭 | 0.85 | 烟火气足但画面冲击略弱 |
| 糖水/甜品 | 0.85 | 颜值高但情绪冲击偏软 |
| 非遗点心 | 0.85 | 故事强、画面强，但品类认知度低 |

### 第 3 步：量级区间测算
```
曝光量级 = 1.5亿 × 引爆力 × 品类系数
客流峰值 = 3000人 × 引爆力 × 品类系数
         （再受产能硬约束封顶，见第4步）
爆红周期 = 2 + 素材续航度/100 个月（莫氏续航82 → 约2.8个月，与实际约3个月退潮吻合，验证公式自洽）
```
- 每个指标输出 **low / mid / high 区间**（mid 为中心值，low/high 为 ±30% 波动带）
- 区间是必要的：**诚实的不确定表达，比虚报的精确数更有决策价值**

### 第 4 步：产能硬约束（承接天花板）
- 读取诊断的 `yellow` 黄线（产能项）
- **客流峰值预测不得高于该店产能承接上限**（如 10㎡档口上限 ~200 人/日，则封顶 200）
- 产能不足的店，预测同时输出"若先补产能（限额/预约/分店），上限可升至 X"

### 第 5 步：置信度
| 档位 | 条件 |
|---|---|
| 高 | 数据完整 + 有对标样本 + 主理人上镜意愿明确 |
| 中 | 部分待核字段 + 品类冷门或对标不足 |
| 低 | 关键字段缺失 / 主理人抗拒出镜 / 完全无对标 |

置信度直接决定建议的"下注力度"：**高置信 → 建议优先投入；中 → 小额试水先验证；低 → 先补数据再谈。**

## 四、变现回报测算（投资视角，对准投资人评委）

### 到店消费
```
爆红期到店营收 ≈ 客流峰值 × 客单价 × 爆红天数 × 上座系数
```

### 直播带货（参考莫氏）
```
直播GMV潜力 = 莫氏基准(30天750万中值) × 引爆力 × 品类系数
```

### 政府/城市溢出价值（这是给政府的独特卖点）
- 莫氏案例证明：单店引爆会带动**整个品类消费**（鸡煲 +84%）与城市文旅热度
- 测算：预估带动"寻味顺德"话题增量、周边业态消费、政府基础设施投入的必要性
- 输出**扶持回报评分**：高 / 中 / 低

### 风险回报
- 若诊断有黄线（产能/健康/人设冲突），在回报测算上打折并注明"需先投入 X 修复"
- 输出一句话：**"投入 10 万修产能预案，预期可承接 3000 万级流量"** 这类可读的投资语言

## 六、行为准则

1. **对标而非玄学**：所有数字必须能回溯到莫氏锚点与诊断分数。
2. **区间而非单点**：永远给 low/mid/high，不许拍单一精确数。
3. **产能是天花板**：预测不越过产能承接上限；超标部分必须标注"需先补产能"。
4. **诚实的不确定**：置信度低就明说，不为了好看调高——错误的自信比保守更危险。
5. **尊重主理人意愿**：主理人抗拒流量的店，即使指数高也只给"轻推"建议。
6. **可读的投资语言**：面向投资评委，结论要能翻译成"投入产出"。

---

## 七、北极星指标（让"可计算"可被验证）

- **命中率**：进入潜力榜 Top10 的店，季度内被验证"开始获得流量"的比例
- **提前量**：平均比引爆早多少天被系统识别（对"提前承接"的价值）
- **回报验证**：扶持投入 vs 带动品类消费的杠杆倍数

这三条指标既是给评委的承诺，也是产品后续上线后自我验证的标准。

---

## 八、与传播 Agent 衔接

- 预言师输出 → 传播 Agent（文旅总策划师）生成：
  - 对店：产能预案 / 限号建议 / 内容投放节奏
  - 对文旅局：潜力店榜单 / 主题线路串联 / 达人资源与话题词建议
- 预测兑现或落空 → 回写数据集，形成"预测反馈闭环"（持续校准模型）

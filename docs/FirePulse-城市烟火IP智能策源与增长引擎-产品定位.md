# 城市烟火 IP 智能策源与增长引擎（FirePulse City）

> **本文档为权威产品定位**，2026-08-15 用户拍板，以此为准。
> 取代前一份「味来引擎 · 七星灶」方案叙述（七星灶不再作为主线，个别好点子可复用）。

- 英文名：**FirePulse City**
- 顺德落地名：**顺德美食流量孵化引擎**（沿用）
- 核心口号：**让每一种地方味道，都拥有一次被全国看见的机会。**

定位转变：不是「美食热点分析工具」，而是**城市烟火 IP 智能策源与增长引擎**。
不是简单地「搜热搜、写文案」，而是帮地方政府完成一条闭环：

> 城市资源发现 → 热点机会研判 → 爆款案例迁移 → 城市故事策划 → 传播效果推演 → 活动组织执行 → 舆情风险控制 → 文旅消费转化 → 城市IP沉淀

**最终卖给政府的不是一个「可能爆火的视频」，而是一套持续生产城市热点的智能化工作机制。**

## 二、Agent 总体全流程：常态监测 + 专题策划 双模式

- **常态监测**：每天自动找热点、找人物、找店铺、找异常增长。
- **专题策划**：围绕春节、五一、龙舟、美食节等节点，生成完整城市传播战役。

```
全网热点雷达/本地资源扫描
    → 爆款基因解析/跨城案例检索
    → 城市创意工厂（故事与活动生成）
    → 传播数字沙盘（多角色模拟评审）
    → 政府人工决策 →〔通过〕内容与活动执行包 /〔修改〕回到创意工厂
    → 实时监测与动态调度
    → 消费转化评估 + 城市IP资产沉淀
    → 回流起点，形成飞轮
```

### 第0步：城市目标设定
政府用户选择本轮任务：推广老店 / 打造草根人物IP / 激活老街商圈 / 策划城市活动 / 承接网络热点 / 节假日前储备选题 / 改善负面标签。输入城市、预算、时间、目标人群、资源范围 → 自动生成《城市传播任务书》。

> 例：国庆前为顺德打造全国性美食话题；人群 18–35 年轻游客；预算 ≤300 万、不依赖明星、不新建设施；转化目标带动伦教、容桂、大良客流与餐饮消费。

### 第1步：全域热点雷达 Agent ——「天眼 · Trend Scout」
持续扫描四类信息：
1. **全国网络热点**：突增食品名、爆火摊主/店主/服务员、情绪金句、城市反差标签、影视综艺体育关联热度、年轻人新打卡方式、城市争议与玩梗。
2. **本地弱信号**：近7日收藏突增、小店视频完播率异常高、评论区大量「求地址」、外地用户占比突增、店主比商品更受欢迎、同一地点被不同博主重复发现、低粉账号高互动。
3. **城市现实资源**：文旅/商务/市监/非遗/交通数据——老字号非遗、历史街区夜市乡村工业遗产、接待能力/营业时间/停车、食安记录与投诉、节庆赛事展会演出日历。
4. **热点窗口识别**：必须回答「为什么是它？为什么是现在？为什么适合这座城市？」——否则只是资源推荐，不是热点机会。

### 第2步：城市IP寻宝 Agent ——「烟火考古局」
把普通资源挖成可传播资产，找五类候选：有绝活的人 / 有记忆的店 / 有画面的食物 / 有参与感的活动 / 有冲突的标签。
每个候选形成一张**城市IP资产卡**：真实人物与地点、历史来源、核心绝活、视觉爆点、情绪爆点、可参与动作、当前承载能力、食安与版权风险、可持续运营周期。

### 第3步：爆款DNA解析 Agent ——「爆点解码器」
把全国案例拆成可迁移的**八种爆款基因**，而非模仿表面形式：
人物基因 / 反差基因 / 视觉基因 / 情绪基因 / 地域基因 / 参与基因 / 事件基因 / 承接基因。

代表案例：景德镇鸡排哥（小商品高情绪价值反差→文旅推介官+秩序承接）、炒粉哥；荣昌卤鹅（美食→人物IP→非遗矩阵→节庆→城市品牌）；淄博烧烤/哈尔滨冰雪/天水麻辣烫/村BA（网络情绪触发→政府快速承接→城市服务放大→消费场景延伸）。

### 第4步：跨城案例迁移 Agent ——「城市灵感迁移器」
结构化映射，不直接说「复制淄博」：

| 外地爆款结构 | 顺德可迁移资源 |
| ---- | ---- |
| 鸡排哥：人物口头禅+情绪服务 | 会讲故事、有仪式感的顺德摊主 |
| 天水麻辣烫：鲜明视觉+地域食材 | 伦教糕、双皮奶、鱼生等制作视觉 |
| 淄博烧烤：饮食方式+城市服务 | 「寻味顺德」线路与商户联合服务 |
| 王婆说媒：NPC+游客参与 | 厨艺师徒、点菜判官、岭南食神角色 |
| 苏超：城市对抗+全民玩梗 | 镇街美食联赛、顺德十镇争味 |
| 影视文旅：情节+取景地巡游 | 美食微短剧与店铺任务线路 |

输出三档方案：**稳健型**（已有资源包装，低投入低风险）/ **突破型**（人物故事+线下活动）/ **现象级型**（全城联动、镇街对抗、短视频剧情+消费场景联动）。

### 第5步：城市爆款创意工厂 ——「灵感熔炉 · Idea Forge」
可解释创意公式：

> 爆款候选 = 在地真实性 × 人物情绪 × 视觉奇观 × 社交参与 × 时间窗口 × 城市承接力

每个候选自动生成：核心话题名、一句话传播钩子、人物故事线、15s/30s/3min 视频脚本、官方+达人+商户内容矩阵、线下特色活动、城市打卡路线、消费券与团购设计、媒体报道角度、海外传播版本、负面舆情预案。

## 三、顺德先推的三个样板爆款

- **A · 凌晨四点，顺德第一笼**：钩子「当大湾区还没醒，顺德已经开始准备今天的第一口鲜。」凌晨4点采购→老师傅第一笼出锅→年轻游客凌晨寻味→清晨限定印章→第一笼编号认证→「顺德凌晨美食地图」。单店流量→城市路线。
- **B · 顺德十镇争味大会**：十镇各派一食+一位民间食神，镇街战队/居民线上投票/游客盲吃/镇长应援/擂台淘汰复活→「年度十大民间味道」。借体育对抗结构，扎根顺德，适合连更短视频+直播+玩梗。
- **C · 00后学徒挑战顺德老师傅**：反差「年轻人不是不喜欢传统，只是不喜欢传统被讲得太无聊」。一刀切鱼、双皮奶凝固挑战、盲辨酱油、方言教学、传统菜年轻化、老师傅评分。覆盖美食+非遗+青年就业+技能传承，汇报价值更高。

## 四、传播数字沙盘（最「华丽」的核心卖点）

方案发布前，让多个虚拟角色模拟评审：
- 外地游客Agent（我为什么专程来？）
- 本地市民Agent（真实还是硬捧？）
- 年轻用户Agent（愿不愿意转发玩梗？）
- 商户Agent（能否参与并获益？）
- 媒体Agent（报道价值在哪？）
- 舆情Agent（可能出现哪些质疑？）
- 监管Agent（食安、价格、客流风险？）

呈现「传播推演剧场」：起爆平台、24h/72h/7天热度曲线、最先参与的用户类型、评论阵营、最容易传播的一句话、负面反转节点、店铺/街区最大承载量、政府介入时点。

**话术边界**：不宣称「准确预测爆款」，表述为「基于历史案例和当前信号，对传播潜力、风险与承接压力进行情景推演」。

## 六、执行阶段：AI 不能只生成文案

方案通过 → 自动生成《城市热点作战包》：7/30/90天传播日历、四级账号矩阵、各账号选题脚本与发布时间、达人类型与合作建议、主视觉/海报/话题页/地图、商户培训手册、接待与排队预案、交通停车志愿者投诉方案、食安巡检清单、舆情回应口径与应急剧本。政府人员只需审批、调整、下发。

## 七、上线后「城市战情室」

实时显示：全网声量、热度增速、外地用户占比、正负面情绪、话题扩散路径、达人贡献度、店铺客流、团购订单、酒店预订、公共交通压力、投诉与食安信号。

Agent 每日三建议：**加热**（热点增长，追加内容/活动）/ **转向**（反响一般，换人物或叙事角度）/ **降温**（客流超载或舆情风险上升，控曝光+加强保障）。

最终一页领导简报：今天火了什么、为什么火、带来多少消费、有什么风险、明天应该做什么。

## 八、政府级安全底线

不能制造虚假故事。明确禁止：
- 编造摊主苦难经历
- 虚构历史传承与非遗身份
- 购买虚假流量 / 组织刷评
- 未经本人同意包装普通市民
- 深度伪造冒充人物发言
- 承载能力不足时盲目引流
- 为流量隐瞒食安问题

每条创意必须带：事实来源、使用授权、AI生成标记、风险审查记录、人工审批记录、方案版本追溯。
——这是政府版产品与普通营销工具最大的区别。

## 九、汇报产品故事

> 「城市烟火IP智能策源与增长引擎」面向地方文旅、商务和宣传部门，构建覆盖热点感知、资源挖掘、案例迁移、创意策划、传播推演、协同执行与消费评估的智能体系统。系统持续感知全国内容趋势和本地弱信号，从特色美食、草根人物、非遗技艺和城市活动中寻找潜在爆点；通过爆款基因图谱和跨城案例推理，形成具有在地真实性的城市故事与活动方案；利用多角色智能体模拟游客、市民、媒体、商户和监管部门的反应，在投放前评估传播潜力、社会风险和城市承接压力；上线后实时监测舆情、客流与消费转化，使偶然发生的网络流量逐步转化为可运营、可复用、可持续的城市品牌资产。

一句话总结：

> 以前是「哪里突然火了，政府赶紧去接」；这套系统要做到「哪里可能火、应该怎么火、火了如何接、热度如何留下」，政府提前知道。

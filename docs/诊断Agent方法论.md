# 诊断医师 Agent · 方法论 v1

> 核心目标：让 LLM 对任何一家顺德店给出**可解释、可追溯、可执行**的爆款诊断，而不是一句玄学结论。
> 关键设计：**证据驱动打分 + 正反样本锚点校准 + 风险门槛审查 + 反事实压力测试**。
> 版本 v1 · 日期 2026-08-14

---

## 一、定位与职责

诊断医师是五步链路（发现→挖掘→诊断→预测→传播）的**核心决策节点**。

职责：
1. 对候选池每家店做"爆款体检"，输出爆款指数 + 诊断报告
2. **独立判断**，不照抄候选数据的预评分（预评分只是校验基准）
3. 给预测 Agent（预言师）提供结构化输入
4. 结论面向政府/投资人决策，必须**可解释**

一句话定位：**"医院体检科 + 风险风控"的结合体——既告诉决策者这家店身体好不好（爆款潜质），也告诉他有什么病（风险），该不该住院观察（要不要投钱扶持）。**

---

## 二、输入与输出

**输入**：单家店的结构化档案（字段见 `docs/顺德美食潜力数据集-模板v1.md`，含预评分 `potentials` + 证据 `evidence` + 风险 `risks`）。

**输出**：结构化诊断报告 JSON（schema 见第七节），供预言师 Agent 和决策面板消费。

---

## 三、诊断五步流程

### 第 1 步：事实核验（防"诊断一个不存在的店"）
- 检查字段完整度，列出 `待核` 项
- 核验店铺真实性（名称/坐标/营业状态是否自洽）
- **产出**：`verified: true/false` + 待核清单

### 第 2 步：逐维评估（核心，见第四节锚点卡）
对五维逐个执行：**引用证据 → 对照锚点 → 打分(0-100) → 给出一句话理由**。
- 必须引用档案里的具体字段/原话作为证据
- 打分是**相对锚点的插值**，不是凭空拍数

### 第 3 步：综合爆款指数
```
爆款指数 = 0.25×人设反差 + 0.25×风味品相 + 0.20×故事叙事 + 0.20×情绪共鸣 + 0.10×素材续航
```

### 第 4 步：风险门槛审查（见第五节）
- 红线 → 一票不推荐
- 黄线 → 降级 + "需先扶持"标注
- 提示项 → 记录在案

### 第 5 步：反事实压力测试 + 分类结论
- **压力测试**："假设这家店明天被千万粉博主拍一条视频，会发生什么？什么会爆、什么会崩？"——模拟流量砸下来的承压能力
- **分类结论**：
  - **A 类**：爆款指数 ≥75 且无红黄线 → 立即纳入孵化观察名单
  - **B 类**：爆款指数 60-75 或存在可修复黄线 → 补齐短板后再评
  - **C 类**：指数 <60 或存在红线 → 暂不推荐（给出不推荐的理由，这对政府避雷很重要）

## 四、五维评分锚点卡（方法论核心）

**为什么需要锚点卡**：LLM 直接打分容易"凭感觉"。锚点卡从真实正反样本提炼每维度的标杆，让打分有参照系、可复现。这是全系统最值钱的知识资产。

### 维度 1：人设反差度（权重 0.25）
"主理人言行与'网红期待'的反差程度"——越不像网红，越有潜质。

| 分值 | 特征 | 真实锚点 |
|---|---|---|
| 95-100 | 有"劝退/自黑/金句"级反差，反流量言行成套出现 | **莫叔**："别拍太火我做不了"、"喝汤可能拉肚子"、60岁生日许愿"早日倒闭" |
| 70-90 | 有鲜明性格/记忆点/反常识习惯 | 无招牌老夫妻"卖完就收"；美姐"粥仙"称号 |
| 50-70 | 有辨识度但无梗 | 橄榄园老板"本地、从容" |
| 30-50 | 有背景但无表达 | 大头华非遗匠人"内敛" |
| <30 | 无个人人设，品牌化/标准化 | 民信老铺、顺峰山庄 |

### 维度 2：风味品相度（权重 0.25）
"地道程度 + 视觉冲击 + 稀缺性"——短视频时代，味道要好，**画面更要好**。

| 分值 | 特征 | 真实锚点 |
|---|---|---|
| 90+ | 现宰/非遗/手作 + 强出片画面 | 莫氏（现宰走地鸡+炭炉瓦煲+药材下锅）；橄榄园（桑基鱼塘+百年橄榄树） |
| 70-90 | 地道风味 + 画面尚可 | 康记鱼生薄切摆盘 |
| 50-70 | 出品稳定但无视觉冲击 | 民信标准化双皮奶 |
| <50 | 工业化/预制感强 | 部分连锁 |

### 维度 3：故事叙事性（权重 0.20）
"能讲多深、能持续讲多久"——人生弧光 > 流水账。

| 分值 | 特征 | 真实锚点 |
|---|---|---|
| 90+ | 完整人生弧光（还债/坚守/翻身/传承） | 莫氏（老中医转行→欠债180万→流量还清）；糖沙翁（奶奶是民国茶楼创始人→近失传守艺） |
| 70-90 | 可讲的传承/坚持故事 | 探记煲仔饭（三百年老宅+月子餐民俗） |
| 50-70 | 有背景但挖不深 | 大头华（非遗+央视） |
| <50 | 无故事或未挖掘 | 冯不记、欢姐伦教糕 |

### 维度 4：情绪共鸣度（权重 0.20）
"能否戳中乡愁/治愈/奋斗/真诚"——爆款本质是情绪传播。

| 分值 | 特征 | 真实锚点 |
|---|---|---|
| 90+ | 原生真诚，击中时代情绪（"不被商业收编的真实"） | 莫氏（全网向往未被商业化的市井烟火） |
| 70-90 | 烟火气/人情味强 | 无招牌老夫妻（老街坊记忆） |
| 50-70 | 一般好感 | 普通家庭店 |
| <50 | 无共鸣点或引发反感 | 高端宴请店（离市井远） |

### 维度 5：素材续航度（权重 0.10）
"这家店够不够拍出 20+ 条不重样的内容"——否则爆一条就枯竭，流量来去如风。

| 分值 | 特征 | 真实锚点 |
|---|---|---|
| 90+ | 人设梗+工艺+场景+排队可无限产出 | 莫氏（金句/斩鸡/汤底/排队/养生） |
| 70-90 | 可拍 20+ 条 | 德记农庄（独特食材矩阵） |
| 50-70 | 可拍 5-10 条 | 糖沙翁（工艺可拆多条，但品类窄） |
| <50 | 一两次就枯竭 | 单品手信店（欢姐伦教糕） |

## 五、风险门槛规则

**风险不是加分项，是门槛**——政府/投资人捧错一家店是灾难。

### 🔴 红线（一票不推荐）
- 卫生资质有公开问题
- 食品安全舆论风险（如鱼生无规范资质/寄生虫争议未解决）
- 违规经营/法律风险
- 严重消费纠纷黑历史

### 🟡 黄线（降级 + "需先扶持"标注）
- 产能严重不足（接不住流量会崩，需提前补产能/限号预案）
- 主理人抗拒出镜/抗拒流量（意愿问题，扶持要尊重主理人意愿）
- 供应链不可持续（如莫氏日均200只超自养能力，后遭口感争议）
- 主理人健康/体力风险（老夫妻作坊）
- 人设崩塌隐患（商业化与人设冲突）

### ⚪ 提示项（记录在案）
- 品类小众认知度低、位置偏远、需预定门槛高等

## 六、反事实压力测试（衔接预测 Agent）

对每家 A/B 类店，诊断报告必须回答：

> "假设明天一条千万粉博主视频引爆这家店，会发生什么？"

分析三件事：
1. **什么会爆**：哪个点最出圈（人设梗？画面？故事？）
2. **什么会崩**：哪个环节先撑不住（排队？产能？供应链？老板心态？）
3. **需要提前做什么**：对应给文旅部门的承接建议（停车/排队区/卫生/限号——像佛山为莫氏连夜修"停鸡坪"那样）

这份压力测试直接作为预测 Agent（预言师）的输入。

## 八、评估原则（Agent 行为准则）

1. **证据驱动**：每个分数必须引用档案具体字段，无证据则降分或标"待核"。
2. **独立判断**：预评分只作对比基准，必须给出自己的判断与分歧解释。
3. **锚点校准**：打分是相对锚点卡的真实插值，不是感觉数。
4. **风险优先**：先查红线，再看分数——红线面前分数归零。
5. **尊重主理人**：政府场景，扶持不得违背店主意愿（莫氏的教训：主理人健康与意愿是底线）。
6. **可解释**：任何结论都能回答"为什么"，用证据链说话。

---

## 九、与预言师 Agent 的衔接

- 诊断报告（含 stress_test）→ 作为预言师输入
- 预言师负责：量级预测 + 置信区间 + **变现回报测算**（投资视角）
- 诊断输出 `level` 决定预言师是否值得为这家店算预期回报（A/B 类才值得算）
